# RC vehicle obstacle-course demo

This repository contains a Gazebo RC truck, a multi-sensor obstacle-avoidance
demo, a live read-only dashboard, and fixed-seed scenario tools. The supported
runtime is Ubuntu 26.04 with ROS 2 Lyrical and Gazebo Sim 10.5.0, on native
Ubuntu or Ubuntu 26.04 under WSL2.
